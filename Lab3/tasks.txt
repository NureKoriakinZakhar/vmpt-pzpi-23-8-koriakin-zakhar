ДЛЯ ЗАПУСКУ СЕРВЕРА:

1. Перейдіть у папку Lab3/server
2. Встановіть залежності: npm install
3. Запустіть сервер: npm start
4. Сервер запуститься на порту 3001 (доступний з будь-якого пристрою у мережі)

Щоб дізнатися IP-адресу комп'ютера:
- Windows: ipconfig  (шукати IPv4 Address)
- macOS: ipconfig getifaddr en0
- Linux: ip a

У застосунку введіть (тільки фізичний девайс в одній мережі з сервером): <IP-адреса>:3001
Наприклад: 192.168.1.42:3001
